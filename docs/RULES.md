# ルール（v0.1）

数値はすべて仮。`src/data/rules.ts` と各データで調整する。

## 能力値

エルデンリングに準拠した8種。

| 能力値 | 役割 |
| --- | --- |
| 生命力 | 最大HP = 30 + 生命力×2 |
| 精神 | 最大FP = 精神 |
| 持久 | スタミナダイスの初期値 = 1 + 持久÷5、上限 = 持久÷2 |
| 筋力・技量・知力・信仰・神秘 | それ自体に効果はない。武器・戦技・カードの能力補正から参照される |

能力補正は「基礎値 + Σ(能力値×係数)」。係数はランクで表示する（1.0以上 S／0.8 A／0.5 B／0.3 C／0.15 D／それ未満 E）。

## 装備

- **重量**: 速度のダイス数、回避コスト、物理の固定軽減を決める
  - 軽装 3d6・回避[3]・軽減0／中装 2d6・回避[4]・軽減1／重装 1d6・回避[6]・軽減3
- **武器**: 通常攻撃（一段目のコストと増加量、最大段数）、戦技、受け能力（カット率）、能力補正
- **盾**: 受け能力のみ。ガード時は武器と盾の高い方のカット率を使う

## ラウンドの流れ

1. **スタミナ回復**: 1ラウンド目は初期値。以降は3個回復（上限まで）。回復量は能力値に依存しない
2. **ドロー**: スタミナダイスを1個払えば1枚引ける（初期手札4枚）
3. **速度**: 各自が重量に応じた nd6 を振り、高い方が先に手番を行う（同値はプレイヤー先手）
4. **手番**: 先手 → 後手

## 手番

1. 手番開始時に、使うスタミナダイスの個数を決めて**まとめて**振る。出目が行動ダイスになる
2. 行動ダイスを払って行動する
   - **武器攻撃**: 手札不要。段ごとに別のダイスで払う
   - **戦技**: 武器ごとに1つ。FPも払う
   - **カード**: 手札から使う
3. 手番終了時、残った行動ダイスは消える。振らなかったスタミナダイスは持ち越し（リアクションにも使える）

## コストの書き方

| 表記 | 意味 |
| --- | --- |
| `[N]` | 合計N以上（お釣りなし） |
| `[N]+[M]` の派生 | 一段目に合計N、二段目に合計N+M。段ごとに別のダイスで払うので、6を1個で両方には使えない |
| `[1の目]` `[偶数の目]` | 指定の目のダイス1個 |
| `[1・2・3を1個ずつ]` | 指定の目を1個ずつ |
| `[4]+FP3` | ダイス合計4とFP3 |

## 攻撃とリアクション

攻撃されたら、残りのスタミナダイスから個数を決めて**まとめて**振り、どれかを選ぶ。使わなかった出目は消える。

- **回避**: 重量ごとのコスト。成功すれば0ダメージ
- **ガード**: コスト = 1 + 受けるはずのダメージ÷6。ダメージはカット率ぶん減る
- **受ける**: そのまま受ける

物理ダメージは防御側の重量による固定軽減を受ける（最低1）。
